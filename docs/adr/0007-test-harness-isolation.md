# Tests are isolated from the host and from each other

- **Temporary directories** come only from `tests/lib/temp.sh` (enforced by `tests/test_temp_safety.py`). `new_test_temp_dir NAME` stores the path in `NAME`; call it directly, not in `$(...)`, so a failed `mktemp` exits the test instead of falling back to the caller's directory (the repo or `$HOME`). `remove_test_temp_dir` refuses every other path. The safety test keeps every refused path inside its own directory, so a broken guard can only remove test data. `tests/syntax` loads the helper beside itself because `REPO_ROOT` can be a fixture.
- **`tests/all`** creates its work and log directories before any suite starts and runs suites from there. Job control (`set -m`) gives each suite its own process group; cleanup sends SIGINT, which lets suites run their own cleanup (SIGTERM does not). Suites run in parallel up to `TESTS_JOBS`, and the report prints in declaration order. `TESTS_PLATFORM_ONLY=1` omits suites whose result cannot depend on the host; the Linux CI job still runs them.
- **Exit 77** means skipped. Python suites that skip a child test exit 77 so `tests/all` reports a skip, never a pass.
- **No host toolchain.** `SetupFixture` removes `MISE_`, `NVM_`, `XDG_`, `NPM_`, `npm_`, `NODE_`, and `CHEZMOI_` variables (only `CHEZMOI_FORCE_UPDATE` is set again) and stubs `mise` to find nothing, so the fake npm answers. Shell fixtures resolve the real `jj` and `git` before they replace `PATH`, and remove host Omarchy commands from plain-Arch fixtures.
- **Rendering.** `render_test_templates DEST FILE...` renders all files in one chezmoi process, because each process reads the whole source tree; when the batch fails, each file renders alone so the error names it. `RENDER_OVERRIDE_DATA` overrides template data. `tests/lint-shell` also renders for the other OS, because CI lints on Linux only.
- **PyYAML** comes from one pinned, hash-checked source archive: `tests/lib/pyyaml-path.sh` holds the version and SHA-256, unpacks only the pure-Python `yaml` package (no installer or build code runs), and prints the directory for `PYTHONPATH`. CI calls it in `managed-npm-safety.yml`; `tests/all` calls it when `python3` cannot import `yaml` and caches the copy in `~/.cache/dotfiles-tests/`. Offline, the YAML cases skip, and a skip is never a pass.
